# שלב 0: פרוטוקול בדיקה

את המשימות P0-1 ו-P0-2 אפשר לבצע רק אצלך: צריך חפצים אמיתיים וטלפון אנדרואיד לצילום. את השחזור מריצים ב-Google Colab, כמתואר בסעיף 4.

## 1. בחירת 10 חפצים
- 4 חפצים מט עם טקסטורה, למשל עץ, קרטון מודפס או צעצוע.
- 3 חפצים חלקים או בצבע אחיד, למשל ספל או קופסה לבנה.
- 2 חפצים מבריקים, למשל חפץ מתכתי או פלסטיק מבריק.
- חלק מכני אחד שתרצי להעתיק.

גודל: בין 5 ל-25 ס"מ.

## 2. מדידה
מודדים בקליבר את 3 המידות של כל חפץ (אורך, רוחב, גובה), במ"מ, ומתעדים בקובץ `scans.csv`. הדוגמה נמצאת בתיקייה `spike/examples/`.

## 3. צילום
- בין 40 ל-80 תמונות לחפץ, בשלושה גבהים ומסביב לכל החפץ.
- חפיפה של כ-70% בין תמונות סמוכות.
- תאורה רכה ואחידה, בלי פלאש.
- רקע עם טקסטורה, למשל עיתון, ולא משטח לבן חלק.
- באנדרואיד: מצלמים במצלמה הרגילה, ברזולוציה המלאה ולא במצב פורטרט. מכבים HDR, ייפוי וזום דיגיטלי, ומשאירים את הפוקוס נעול על החפץ (לחיצה ארוכה על המסך).
- החפץ לא זז. מי שזז הוא המצלמה.

## 4. שחזור והערכה ב-Google Colab (מומלץ, לא צריך מחשב חזק)
1. בטלפון, באפליקציית Google Drive, יוצרים את התיקייה `scan-to-print/photos/`, ובתוכה תיקייה לכל חפץ עם התמונות שלו.
2. יוצרים את הקובץ `scan-to-print/scans.csv` עם העמודות `object_id,dim1_mm,dim2_mm,dim3_mm`. שם החפץ חייב להיות זהה לשם התיקייה.
3. פותחים את המחברת [`notebooks/phase0_colab.ipynb`](https://colab.research.google.com/github/d0548450344-dotcom/scan-to-print/blob/main/notebooks/phase0_colab.ipynb) ב-Colab, בוחרים T4 GPU ומריצים את התאים לפי הסדר.

המחברת בונה את המודל של כל חפץ, מסירה ממנו את השולחן, מעמידה אותו זקוף, ומפיקה דוח המשך או עצירה. כל התוצאות נשמרות ב-Drive, בתיקייה `scan-to-print/results/`.

**לא מומלץ לבדיקה הזו:** אפליקציות סריקה לאנדרואיד כמו Polycam, ‏KIRI Engine או RealityScan. הן ימדדו את המנוע שלהן ולא את COLMAP, שבו נשתמש בפועל. אפשר להשתמש בהן להשוואה בלבד.

## 5. הערכה משורת הפקודה (רק אם לא עובדים ב-Colab)
```bash
scan2print evaluate scans.csv --report out/report.csv
```
הפקודה מכיילת את קנה המידה של כל חפץ לפי המידה הארוכה ביותר שלו, ובודקת את שתי המידות האחרות. סטייה מותרת: 1 מ"מ לכל 100 מ"מ. **כדי להמשיך, לפחות 7 מתוך 10 החפצים צריכים לעבור.** חפץ שהשחזור שלו נכשל נספר ככישלון.

## 6. הכנה להדפסה של חפץ בודד
```bash
scan2print prepare work/obj1/dense/0/meshed-poisson.ply out/obj1.3mf --known-mm 120 --cut-mm 1
```

## מגבלות של הכלי
- השיטה מניחה שהמידות שמדדת בקליבר מקבילות לצירי התיבה המינימלית שמקיפה את המודל. בחפצים לא סימטריים זה קירוב בלבד.
- החפץ צריך לעמוד על משטח שטוח שנראה היטב בתמונות. המחברת מזהה אותו כשולחן ומסירה אותו.
- מתחת לחלק שבולט מהחפץ (למשל ידית של ספל) עלולה להישאר פיסה דקה של שולחן.
- סגירת חורים מתמודדת רק עם חורים פשוטים. מודל שנשאר לא סגור יסומן בדוח.
